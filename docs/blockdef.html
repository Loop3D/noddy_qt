Block diagram display type

This window controls the display behaviour of block diagrams, and can accessed via the Volume/Surface Options Window, in which case it controls the default display behaviour of all block diagrams, or it can be used to control the behaviour of individual block diagram windows by clicking in the block diagram window with the right mouse button.

Three types of display are available:

  • Solid Block which show the outside surfaces of the block coloured according to rock type;
  • Specific Layers, that allows layers de-selected in the Layers list to be made transparent, and various
  • Rock Property Displays that displays voxels according to the magnitude of one of their rock properties.

The last two modes may used in combination to show, for example, the a block diagram showing only the density variation within a single layer (all other layers being transparent).

Display Type window

Display TypeThis menu controls the parameter which will be used to define the colour and transparency of individual voxels in the model.
LayersAll LayersWhen selected, it makes all layers visible, otherwise only selected layers will be displayed
LUT EditingStretch over RangeStretches range of look up table to match range of rock property values found in model
Clip within RangeAllows user to define range of look up table to specific values, which is useful when comparing different models
ResetResets look up table to complete range
Calc Real ValuesCalculates maximum and minimum values for rock proporty in model (performed automatically after first display of new model)
MaxMaximum (as % or real values) to which look up table is clipped, clipping may also be performed interactively with mouse by clicking in look up table
MinMinimum (as % or real values) to which look up table is clipped, clipping may also be performed interactively with mouse by clicking in look up table
Show TopoWhen a topography file is loaded (Block Options > Use Topography) and the display type is Specific Layers, tick Show Topo to leave out every voxel above the topographic surface, so the block shows the land surface.
