Noddy

Noddy builds a 3D geological model from a sequence of simple kinematic events — folds, faults, unconformities, dykes, plugs and more — and forward-models the gravity and magnetic response of that model.

This is the user guide for the current, open-source Qt version of Noddy maintained at github.com/Loop3D/noddy_qt. It runs on Windows, macOS and Linux.

The Noddy window

When Noddy starts you see the Toolbar, containing one icon per event type, and the empty History window. Events are dropped from the Toolbar into the History window in the order they happened; each event opens a window where its parameters are set and previewed.

Noddy was first written by Mark Jessell at Imperial College (1981–82), developed at Monash University (released 1994), and is now maintained at The University of Western Australia. See Introduction & credits.
