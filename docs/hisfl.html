History file

File versionHistories written by the current version have format version 8.0.2 (shown in File > About Noddy). This version adds the Gaussian noise settings to the geophysics options section. Older history files can still be read.

History File Format

This is an ASCII text file generated by the File > Save History menu item from the File menu, which contains a full summary of the stratigraphies defined to that stage, together with the current structural history, and all option settings for geology, geophysics and 3D views.

This file format allows for full editing outside of the framework of the program, using any standard text editor, so that modified models can be created externally.

There are a number of conventions which must be obeyed in order for the file to retain a valid format when editing these files:

A) Comment lines- any line which starts with a # symbol is ignored when read in

B) Blank lines- all blank lines are ignored when read in

C) All lines with information to be read contain an equals sign, and the information to be read follows the equals sign. Any value after an equals sign may be altered, however altering the number of stratigraphies, the number of layers within a stratigraphy, or the number of events will have a trickle down effect requiring further editing.

D) The internal order within thematic blocks of data must not be altered, and the order of block groupings must also be preserved, specifically the block groupings (in bold below) must be:

i) Header Information- File Type

Version Number

ii) Stratigraphic Information- Number of stratigraphies

Number of layers in 1st stratigraphy

Layer info 1st layer/1st strat:height

density

magsus

colour

Layer info 2nd layer/1st strat: etc

iii) Deformation Information- Number of events

Event info. for 1st event: type info for that type

Event info. for 2nd event: etc

iv) Geology Options-All options from Geology options window

v) Geophysics Options-All options from Geophysics options window

vi) 3D Options-All options from 3D view options window

vii) Icon positionsThe position of icons in the history window

viii) End of file check-Test for correct reading of data file

Editing this file can be accomplished in two ways, either by changing the value of a parameter after an equals sign, or by changing the order of events by reshuffling entire event descriptions. The event numbers which are associated with each event type do not need to be altered as they are simply for external reference.
