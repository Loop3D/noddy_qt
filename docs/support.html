Support & bug reports

Noddy is open-source software maintained on GitHub. Questions, bug reports and suggestions are welcome:

  • Report a bug or request a feature: open an issue at github.com/Loop3D/noddy_qt/issues. Please attach the history file (.his) and describe the steps that cause the problem.
  • Source code and releases: github.com/Loop3D/noddy_qt
  • Background and publications: tectonique.net/noddy

See also Troubleshooting.
