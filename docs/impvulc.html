Importing Vulcan block models

This menu allows Vulcan format block models to be converted to the .g00 series Noddy block model formats (which can then be used via the Import Deformation Event).

Vulcan can export a regularised block model with the following ASCII format, one line per voxel:

x_location y_location z_location x_voxel_size y_voxel_size z_voxel_size rock_name_index density mag_sus

Using the Import Block->Vulcan menu item from the Tools menu, you are able to convert this into standard indexed Noddy block model files. This format may then be imported into the model using the Import event, or geophysical anomalies may be directly calculated on the block using the Geophysics > Calculate Anomalies >Calculate Anomalies from Block menu item.
