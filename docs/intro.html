Introduction & credits

The aim of Noddy is to allow integrated forward modelling of geological structures together with the gravity and magnetic anomalies they produce. The complex structure of a poly-deformed area is built up as a sequence of simple 3D kinematic events, so a geoscientist with a reasonable understanding of the geology of an area can refine that understanding by interactively changing the geometry and the physical properties of the rocks. A systematic set of models was published as Volume 5 of the Journal of the Virtual Explorer; the more recent Noddyverse collection contains a million random models generated with the same code (see Random histories).

History of the program

The structural modelling in Noddy was first written by Mark Jessell as part of an MSc at Imperial College, University of London, in 1981–82, as an interactive map-creation package. It was developed into a full geological and geophysical modelling package at Monash University, released in 1994, with funding from the Australian Research Council, the Australian Geodynamics CRC and AMIRA project P418. The Windows version was additionally developed by Encom Technology Pty Ltd, who no longer support it. Version 6.0 was released in April 1998 and version 7 followed.

The current version, maintained at The University of Western Australia, replaces the original XVT user interface with Qt 5 so that Noddy runs on current Windows, macOS and Linux systems, and adds a number of new features (see What's new).
