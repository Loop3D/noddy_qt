Printing and saving images

Printing windows

Click on the window you want to print, choose File > Page Setup… to select a printer and page layout, then File > Print Page. Exact scaling of the print is not available, but the overall size can be changed with Scale Printing by in Edit > Project Options.

Saving windows to file

Click on the window you want to save, then choose File > Save Picture…. The contents of the window are saved as a PNG image.

File > Read Picture… opens an image (BMP, PNG, JPEG, …) in its own window, which is useful for comparing scanned maps, sections or geophysical images with the model.
