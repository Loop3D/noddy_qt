Base stratigraphy

In order to define a Base Stratigraphy (which must be the first event in a history) event place a Base Stratigraphy icon in the History window. You will then be provided with the Base Stratigraphy definition window.

GROUPNAMEFUNCTION
Event NameNameName of Stratigraphic sequence
Stratigraphic LayersList of all layers curently defined for this stratigraphy
EditEdit Rock Properies (eg thickness, density, name, colour etc) for currently highlighted layer
Move UpMove currently highlighted layer up in sequence
Move DownMove currently highlighted layer down in sequence
AddAdd a new 1000 m thick layer above highlighted layer
DeleteDelete highlighted layer
