Importing DXF surfaces

Not Available in Version 6.0

Closed single or open multiple triangulated surfaces can be converted into the .g00 Noddy block model format (which can then be used via the Import Deformation Event). Once the triangulation has been loaded (which can take a long time), the resolution of the Noddy block model can be defined.
