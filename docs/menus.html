Menu reference

Every menu in Noddy is listed below. Some items are only available when they make sense — for example the topography items need a topography file, and Plot Orientations needs orientations measured on a map.

File

Reading and writing files, pictures and printing.

ItemWhat it does
New HistoryClear all events and start again, from the factory defaults or from your own defaults file.
Read History…Read a history (.his) file. If a history is loaded you can merge the two or overwrite the current one.
Random HistoryReplace the current history with a randomly generated one. new
Save HistorySave the current history to its file.
Save History As…Save the current history under a new name.
Save as DefaultsSave the current history as defaults.his, used by New History > User Defaults.
Load Reference Images > Geological… / Gravity… / Magnetics…Load a picture, .grv or .mag file as a reference for comparison and difference images.
Movie > Create… / Load…Record the evolution of the model frame by frame, or replay a saved movie (.nmv).
Read Picture…Open an image file (BMP, PNG, …) in a window, e.g. a scanned map for comparison.
Save Picture…Save the front window as a PNG file.
Save Orientations…Save the orientation symbols plotted on the current map, with their X, Y, Z.
Save Surface Orientations…Save bedding dip, dip direction and lithology on a grid over the model surface (CSV). new
Save Profile…Save a profile drawn across a geophysics image.
Page Setup… / Print PageChoose a printer and print the front window.
About Noddy…Version, history-file format version and licence.
ExitQuit Noddy.

Edit

Editing the history and setting options.

ItemWhat it does
UndoUndo the last change in the History window (one level).
Cut / Copy / Paste / Clear / DuplicateMove, copy or delete the selected events.
Select AllSelect every event in the History window.
Tidy WindowClose up gaps between icons in the History window (the history itself is not changed).
Project Options…Calculation location, length unit and print scaling.
Block Options…Model volume, cube sizes, false origin and topography.
Movie Options…Movie type, frames per event and replay speed.
Geology Display Options…View direction and scale, chair diagrams, background colour.
Geology Section/Borehole Options…Position and orientation of sections and boreholes.
Geology Volume/Surface Options…Default block display and 3D triangulation surfaces.
Geophysics Calculation Options…What to calculate, calculation scheme, padding and Gaussian noise.
Geophysics Survey Options…Earth's field, survey altitude, remanence and anisotropy.
Geophysics Display Options…Image scaling and default gravity/magnetic display.
Window Options…Default position and size of each type of window.

Geology

Geological visualisations.

ItemWhat it does
Block Diagram3D block diagram of the model.
Map > Solid Colours… / Lines…Plan view of the geology at the top of the block or on the topography.
Topo MapContours of the loaded topography (available once topography is loaded).
Section > Solid Colours… / Lines…Vertical section through the model.
Stratigraphic ColumnAll stratigraphic sequences and their rock properties.
Borehole > Generate > 3D / SchematicGeology along the borehole defined in the Section/Borehole Options.
Borehole > Import > 3D… / Schematic…Geology along a borehole read from a file.
3D TopoGeology draped over the 3D topography (available once topography is loaded).
3D TriangulationTriangulated 3D surfaces of layers and discontinuities.
Plot OrientationsPlot the orientations measured on a map on a stereonet.

Geophysics

Calculating and displaying gravity and magnetics.

ItemWhat it does
Calculate Anomalies > Anomalies…Calculate gravity and magnetic anomalies of the current model.
Calculate Anomalies > Block and Anomalies…As above, and also save the block model.
Calculate Anomalies > Anomalies from Block…Calculate anomalies from a saved block model.
Calculate Anomalies > Borehole > Generated / Imported…Down-hole gravity and magnetics along a borehole.
Calculate Anomalies > XYZ Point Data > Import From File… / Generate…Anomalies at arbitrary survey points.
Difference with Reference > Gravity… / Magnetics…Subtract a calculated image from the loaded reference image.
Display Image > Gravity… / Magnetics… / Magnetics X, Y, Z…Display a saved .grv or .mag image.
Display Profile > Gravity… / Magnetics…Display a saved profile.

Tools

Import and export.

ItemWhat it does
Import Block > Dicer… / Vulcan… / Old Noddy Block…Convert other voxel formats to Noddy block models.
Import Image > ASCII… / Column…Convert gridded or column data to Noddy .grv/.mag images.
Export Block > Noddy Block Model…Save the block model in Noddy format.
Export Block > Raw Voxel Model…Save the voxels as a raw array.
Export Block > Tabulated Columns…Save the voxels as text columns.
Export Block > DXF - 3D Faces / DXF - PolylinesExport the 3D triangulation as DXF.
Export Block > VulcanExport the 3D triangulation in Vulcan format.
Export Block > Tomofast-x Inversion Files…Input files for Tomofast-x gravity, magnetic and joint inversion. new
Export Block > TransD Inversion Files…Tomofast-x files plus TransD parameter files. new
Export Image > ERMapper > Gravity… / Magnetics… / Line Map…Export images and line maps to ER Mapper.
Export Image > Geosoft > Gravity… / Magnetics…Export images as Geosoft grids.
Edit Rock Database…Edit the global rock property database.

Windows

Arranging windows.

ItemWhat it does
Cascade / TileArrange the open windows.
Default SizeReturn the front window to its default size.
Remove AllClose all visualisation windows.
LegendShow the legend for the front window.
(window list)Bring any open window to the front.

Help

ItemWhat it does

Extra menus for map windows

When a Map or Topo Map window is in front, four more menus appear. They control the orientation symbols you click onto the map; see Maps.

MenuItems
SymbolBedding, Foliation, Lineation, Bd - Cl (bedding/cleavage intersection), Cl - Cl (cleavage/cleavage intersection)
Event 1The event whose foliation or lineation is measured
Event 2The second event, for Cl - Cl intersections
DefinePosition of Event 1: click on the map to move that event
