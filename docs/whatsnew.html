What's new in the Qt version

The original Noddy user interface was built with XVT, a commercial cross-platform toolkit. The current version replaces XVT with Qt 5, so Noddy runs natively on current Windows, macOS and Linux systems and can be built from source by anyone. The modelling and geophysics code is the same; the changes below are the user-visible differences.

Changed behaviour

  • Pictures are PNG. File > Save Picture… and movie frames are written as PNG files instead of BMP. Read Picture and Trace From Image accept BMP, PNG and other common image formats.
  • Default calculation scheme. New histories use the Spectral calculation scheme with Reflection padding (previously Spatial with Ramp padding).
  • Event previews default to Block rather than Plane.
  • History file format is now version 8.0.2; it stores the Gaussian noise settings. Older history files still load.
  • Licence. Noddy is open source under the MIT licence; the licence-key mechanism and its Licence menu item have gone.
  • The program version is shown in File > About Noddy….

Removed

  • Vertical Derivatives (Geophysics menu) — the First/Second derivative calculations have been removed. Use an external package such as Geosoft or QGIS on exported grids instead.
  • In-program help. The Help… buttons in dialogs are disabled and the Help Viewer setting in Project Options is not used. Help > Contents now opens this online documentation in your web browser.
  • Licence menu item and licence files.
  • CD-ROM installer. Noddy is distributed as downloads from GitHub; see Installing Noddy.
