Command-line (batch) mode

Noddy can run without its user interface to process history files in scripts. If Noddy is started with a history file name (any argument containing .his) or with -random, it runs the requested calculation, writes the results and exits.

noddy <history_file> [options]
noddy -random [options]
OptionEffect
-h history_fileHistory file to read (alternatively give it as the first argument)
-o output_fileBase name for output files (extensions are added)
-b block_fileBlock file to write or read (with -anomAndBlock and -anomFromBlock)
-blockWrite a block model of the geophysics area
-dicerAs -block, but in Dicer format
-linemapWrite a geological line map
-sectionWrite a geological section
-geoBlockWrite a geological block diagram
-anomCalculate gravity and magnetic anomaly files
-anomAndBlockAs -anom, and also write a block file
-anomFromBlockCalculate anomalies from an existing block file
-profileForce a profile to be calculated
-imageForce an image to be calculated
-dxfface newExport the 3D triangulation surfaces (discontinuities and stratigraphic break planes) to the output file as a DXF 3DFACE mesh
-dxfline newExport the 3D triangulation surfaces as a DXF POLYLINE (polyface) mesh
-random newGenerate a random history instead of reading one; writes a time-stamped .his file, a block model and anomalies. See Random histories.
-help, -?Show the usage message

Examples

noddy model.his -o model -anom          # model.grv and model.mag
noddy model.his -o model -block         # block model of the geophysics area
noddy model.his -o model.dxf -dxfface   # 3D surfaces as DXF
noddy -random -o synth                  # random history + block + anomalies

On a machine without a display (a server or CI job) add QT_QPA_PLATFORM=offscreen before the command on Linux and macOS.
