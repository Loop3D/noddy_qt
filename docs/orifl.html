Orientation data file

This is an ASCII text file (tab delimited) which contains the orientation data for the current outcrop map. This created using Save Orientations option from the File menu. The data provides information on orientation, feature type, and age of feature:

Dip/PlungeDipDn/PlDnTypeFeatureAge1Age2
4753PlaneBedding
7866PlaneFoliation1 Fold
45134PlaneFoliation3 Fault
44134LineLineation3 Fault
17340LineLineation1 Fold
17340LineBedding-Cl1 Fold
44144LineCl-Cl1 Fold3 Fault

Orientation files may be opened up directly by spreadsheets such as Lotus 1-2-3, Excel, etc for later processing.

X, Y, Z columnsEach row now also ends with three columns X, Y and Z giving the location of the measurement in model coordinates. The header line is:
Dip/Plunge  DipDn/PlDn  Type  Feature  Age1  Age2  X  Y  Z
To sample bedding over the whole model surface instead of individual clicks, see Saving surface orientations.
